# AI Document Text Summarizer

A simple web application that summarizes pasted text and uploaded documents using FastAPI and Hugging Face Transformers.

## Features

- Summarize pasted text
- Upload and summarize TXT files
- Upload and summarize text-based PDF files
- FastAPI backend
- HTML, CSS, and JavaScript frontend
- CPU-friendly Hugging Face model

## Tech Stack

- HTML, CSS, JavaScript
- FastAPI
- Hugging Face Transformers
- PyTorch
- PyPDF
